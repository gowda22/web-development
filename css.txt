7. Transition vs Animation vs Transform
This is a very important interview comparison.
Transform	Transition	Animation
Changes element appearance	Makes changes smooth	Creates timed visual changes
Does not define duration	Uses duration	Uses duration
Can move, rotate, resize	Usually starts when a property changes	Can start automatically
Does not need keyframes	Does not need keyframes	Can use @keyframes
Example: rotate(30deg)	Example: transition: 1s	Example: animation: move 3s
